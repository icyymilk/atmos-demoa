## 产品定位与实现思路

Atmos 是一个通过自然语言创建、迭代网页应用的 Agent 工作台。体验者填写自己的模型 Key，Agent 按任务自主调用工具，读取结果并继续执行，直到交付检查通过或触发明确停止条件。前端实时展示公开进度、当前文件、草稿和已验证预览，生成结果保存为可恢复版本。

技术栈为 React + TypeScript、Vinext/Vite、Worker API、D1/SQLite 与 Node Harness。工具通过官方 MCP SDK 接入，支持本机插件目录与按需加载 Skill；生成应用使用原生 HTML/CSS/JS 和隔离 iframe，应用状态也通过宿主接口持久化。

## 已实现

- **核心流程**：访客初始化、邮箱注册/登录/退出/改密，创建应用、多轮修改、实时文件/预览、历史版本、恢复、完整文件 ZIP 和独立 HTML 导出。
- **真实 Agent 循环**：模型自主选择工具，真实执行与结果反馈；工具与轮次预算、超时、停止、重复调用检测、输出截断恢复、分块写入。
- **模型控制**：DeepSeek、OpenAI、OpenRouter、Qwen，可读取模型列表或手填 ID，设置推理强度/输出预算并测试连接；Key 仅保留页面内存。
- **扩展能力**：网页读取/检索、文件与任务管理、stdio/HTTP/SSE MCP、插件、Skill；GitHub/GitLab/Notion 令牌连接及只读工具。
- **个性化记忆**：账户级 Markdown 文档索引、双向链接关系图、常驻与检索记忆。Agent 只提出候选，用户确认后才记住。
- **渐进上下文**：近期摘要、历史索引、相关节选，历史/记忆按需读取；旧工具记录成组压缩。
- **可控授权**：总是询问、重要询问、完全允许。高风险命令/删除/未知副作用工具执行前审批，绑定原始操作且不可重放。
- **交互打磨**：系统字体、统一线性图标、天蓝色主题、粒子动效、可收起侧栏、分段工具栏、键盘快捷键、手机适配和服务健康状态。

## 建议演示顺序（5–8 分钟）

1. **零门槛体验**：点击任务看板模板，新增任务、修改状态，刷新确认保存。模板明确标注“不调用 AI”。
2. **注册与继承**：注册账户，确认访客项目保留；邮箱是登录名，首版不验证邮箱。
3. **真实生成**：配置体验者 Key、选择模型和推理档位，测试连接；输入“保留看板现有功能，增加按关键词搜索任务”，观察 Agent 调用、文件更新和预览。
4. **持续修改与交付**：再提出一次具体修改，在预览中验证；查看源码/历史，下载完整项目 ZIP，解压打开 `atmos-export/preview.html`。
5. **个性化亮点**：在记忆中心主动保存一条界面偏好，创建带 `[[USER]]` 引用的文档，在关系图查看链接；说明 Agent 新记忆先进入待确认。
6. **用户掌控**：查看“信任与审批”的三级模式与审批记录；运行可随时停止，失败不会伪装成已完成。

快捷键：⌘ / Ctrl + K 聚焦输入，⌘ / Ctrl + , 打开模型设置，⌘ / Ctrl + \ 显示/隐藏侧栏，Esc 关闭弹窗。

## 验证与能力边界

本地验证包含：单元测试、类型检查、Lint、生产构建、真实 API 回归、真实 MCP 副作用与审批测试、桌面/手机浏览器交互，以及干净数据库初始化和编译后服务启动。详见 [验收矩阵](RELEASE-CHECKLIST.md)。

真实模型决策的自动化测试采用明确的测试夹具；**有效 Key 下的首次成功生成、多轮修改及正式公网验收，须在交付前完成并记录**，不会用模板或 mock 冒充。

生成范围是可直接运行的单页前端应用，ZIP 导出全部工作区文件但不包含 Git 历史。首版不生成任意 npm/后端工程，不支持原生移动应用、真实支付、实时外部 API、独立容器内执行任意 Bash。注册不含邮件验证/找回；跨浏览器数据共享限同一服务实例。全局记忆/MCP 状态使用本机持久化，需要随数据库一起备份。

## 关键取舍与后续优先级

- 用真实单 Agent 工具循环体现 harness 工程，避免为了演示角色而写死步骤。
- 原生单页应用降低依赖构建复杂度，优先打通“需求 → 工具执行 → 预览 → 保存 → 再迭代”。
- BYOK 降低公开体验成本并给用户模型选择权；不保存模型 Key。
- 稳定 owner 与登录会话分离，使注册继承、项目隔离和跨项目记忆可复用。
- 首层摘要与按需检索控制上下文体积；审批绑定具体操作，用户拒绝后由 Agent 选择替代路径。

后续优先级：P0 完成正式公网/真实模型质量回归与基础运行监控；P1 邮件验证/找回、运行配额、任务队列、断线恢复；P2 多文件工程执行器、自动浏览器修复、GitHub 写入同步与独立应用发布。

产品边界参考 [Atoms 项目范围与能力](https://help.atoms.dev/zh/articles/12129503-project-scope-capabilities)。Atmos 是独立实现的挑战 Demo，不是 Atoms 官方产品。
